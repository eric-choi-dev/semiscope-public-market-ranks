# Semiscope public market ranks

The integrated long-term model produces one entry score for each eligible US exchange listing. The 126-session and 252-session views use the same 0–100 index and rank with separate realized holding periods. Each published row includes both view packets, the trading date and ticker. Tied scores share a rank. An eligible issue without sufficient verified history has an exclusion reason.

Each index evaluates the size of the drawdown and price conditions using the stock’s own split-adjusted history. A score of 80 or more qualifies as an entry signal and may occur while the price is falling. Each row shows the price phase separately. The packet includes the model version, and the snapshot includes the source digest and trading date. Realized doubling rates use subsequently observed market prices.

The calculation matches the Nasdaq Trader directory date to completed, commit-pinned OHLCV data. If the directory advances before prices, the previous ranking keeps its trading date. Scores and ranks are adapted from [DoltHub stocks](https://www.dolthub.com/repositories/post-no-preference/stocks) and published under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

[Public ranking JSON](https://semiscope-ranks.deed.page/data/long-ranks.json)

The scheduled workflow checks at 07:17 and 15:41 UTC. Each successful publication records its date, digest, coverage, price revision and directory checksum in `last-run.json`. The matching listing directory is archived in `last-directory.json.gz`. Workflow dispatch with `verify_current` reproduces the current release from that directory and its historical price revision.

The workflow retains the eight most recent verified Nasdaq directory dates in `pending-directories/`. When price history arrives a day behind the newest directory, it can publish that completed price date using the matching archived listings. A missing matching directory leaves the previous publication in place.

The one-time `migrate_unified` update to `long-entry-index-5.0` uses the November 23, 2026 cohort and the exact version 8 release. `node scripts/refresh-cloud-ranks.mjs --check-packets-file <file>` validates the decoded packets, single score across holding periods, thresholds and tie ranks offline. Compare a candidate against the pinned public data and official exchange roster with `node scripts/refresh-cloud-ranks.mjs --review-unified-candidate <file>`. Dispatch the migration with its `expected_content_sha256`. A separate cloud rebuild must reproduce the reviewed content digest before it can publish against the verified prior release. The publishing key is specific to the numerical data site.

The same schedule independently extends the [public daily price history](https://github.com/eric-choi-dev/semiscope-public-market-ranks/tree/history-deltas). It starts from the 4,389-symbol November 20, 2026 release and appends completed sessions from one pinned Dolt revision. Each update checks the preceding day, corporate actions and coverage, and records a content hash. A symbol whose price basis can no longer be verified is omitted from later daily updates. The data branch contains only CC BY-SA numerical files and attribution. Ranking publication and price-history publication can advance independently.

## Large-cap stock discovery

The public [latest screen](quality/latest.json) and [dated snapshots](quality/) accompany the raw rankings. Each constituent issue must match the dated [Wikipedia S&P 500 roster](https://en.wikipedia.org/wiki/List_of_S%26P_500_companies), the Nasdaq directory, and its issuer in [SEC EDGAR](https://www.sec.gov/search-filings/edgar-application-programming-interfaces). We estimate capitalization using the same market close and Dolt revision as the rank release, multiplied by the most recent verified SEC share count and any intervening stock splits. The share count must be dated within 150 days of the price and the filing must precede the price date. The inclusion threshold is USD 10 billion. Rows retain issuer, quote, shares, measurement date, filing date, original filing link, calculation basis and reason.

Where multiple common classes exist, a documented class alone can establish a lower bound on the issuer. A class lower bound below the threshold leaves eligibility unproved. Rows with missing, stale or conflicting evidence are excluded. The website reranks scored issues within this universe and shows both eligible and scored counts. ETFs and market benchmarks can be researched directly.

The same scheduled job refreshes the screen after it verifies the rank and directory receipts. It publishes a dated file without replacing prior trading days. A current screen must be at most ten calendar days old, with a roster revision no more than 45 days older than the quote. As an independent release check, all 503 roster tickers for November 23, 2026 matched [State Street SPY's dated holdings workbook](https://www.ssga.com/library-content/products/fund-data/etfs/us/holdings-daily-us-en-spy.xlsx). The sponsor's public download rolls daily. The dated JSON records its checksum. The derived roster and price data retain [CC BY-SA 4.0 attribution](https://creativecommons.org/licenses/by-sa/4.0/).

The read-only `audit_quality` workflow dispatch independently checks the dated constituent roster, a sample of original SEC title/share disclosures, and corresponding close and split inputs against the published screen. It includes both issuer-wide and class-specific cases when available.
